# Contributing

Pull requests and design feedback are welcome for maintainer review. Submitting
a contribution does not grant permission to use, modify, deploy, or
redistribute Rabbithole; those rights require prior written permission under
the `LICENSE`. Rabbithole is looking for design partners, so contact the
maintainers through the issue tracker in this repository to discuss
collaboration and request permission.

Use synthetic fixtures only:
never include a real learner's identity, educational record, transcript,
photograph, account identifier, or production-derived example in a commit,
branch, pull request, issue, test, screenshot, or generated artifact.
