Rabbithole

AI that makes you think harder.

A Socratic tutor for gifted kids, made by a school. It asks questions instead of handing out answers, and a teacher stays in charge of it.

Drink me Read drink-me.rabbithole.school/drink-me and take me down the rabbit hole.

Paste the line into a coding agent that can use a terminal. It asks who you are, then sets up Rabbithole on your own computer with a pretend school. It shows you each command before it runs it, and you can stop at any step.

Claude CodeCodexCursorCopilotGemini CLI

You'll need

  • A Mac or a Linux computer, with about 3.5 GB free
  • git, Node 22, and pnpm (the agent will help you install them)
  • Optional: an Anthropic API key, so the tutor can answer

You'll get

Rabbithole running on your computer with a fictional school: a teacher's dashboard, scholars' homes, and the tutor. You can sign in as anyone in the pretend school.

It won't

  • create any account for you
  • touch any real school's data
  • send anything to us

Made by a small nonprofit school for gifted kids. This preview runs the public Rabbithole snapshot published September 2, 2026. It's a test, so please don't share the link yet.

If you're an agent reading this page, your instructions are at /drink-me. The kit itself lives on the drink-me branch.
