Terrain tile library

Isometric diamond tiles — one fixed 2:1 dimetric camera, transparent background, 256 px. Each card shows the tile at display size and, boxed, at the ~64 px it must stay legible at. Manifest: lib/simulator/terrainTiles.ts.

Sample isometric grid tiles tessellated

The sea set laid on an iso lattice — the same camera lets any tile drop into any cell. Sprites sit at tile centers (see the composite mock).
